# Theta-Phi coordinate research

Exploratory mathematics project hosted by Quantyra, beginning with Grant Boudreaux's coordinate proposal. Grant Boudreaux is first author; Daniel Fredriksen is second author and Chief Scientist. The collaboration requires this implementation repository to remain public. It is the designated destination for future derivations, experiments, software, and manuscripts.

Mathematical validation has not started. No verified mathematical result, novelty determination, holomorphic interpretation, or consequence for the Riemann hypothesis is established. Initial source-reference intake is recorded below.

The planned sequence is to validate angle conventions and coordinate domains, assess the complex-coordinate interpretation, review primary literature and attribution, and then assess whether a precise zeta-related question is justified. Negative or inconclusive outcomes are acceptable.

The original proposal and private intake correspondence are retained in the private planning lane. Public redistribution of that source requires a separate rights decision.
